# Voice Agent Desk (synthetic)

Phone-friendly static prototype for REGAL Senior Product Manager interview practice.

## Wedge
Live campaign board, QA queue with transcript snippets, escalation desk, and a quality gate that can pause dialing. Not a generic call-center wallboard and not an eval grid hero.

## Run
Open `index.html` in a browser. No build step.

## 90-second path
1. Board shows containment slip while Live
2. QA: Fail wrong-party, Escalate payment-coercion
3. Quality gate fails safety to Pause campaign
4. Resolve escalations, clear QA to Resume when checks pass
