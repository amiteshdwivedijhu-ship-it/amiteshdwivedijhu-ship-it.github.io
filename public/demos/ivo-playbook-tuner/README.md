# Playbook Tuner

Unlisted static prototype. Open `index.html`. No build step and no network calls.

Synthetic negotiations for a fake company, Corvid Systems. Not an Ivo product. Not legal advice. Clause text is made up.

The tool ranks provisions from 120 closed MSAs, proposes one playbook change, and will not publish it unless the simulation stays inside the risk bar and a named GC signs off.
