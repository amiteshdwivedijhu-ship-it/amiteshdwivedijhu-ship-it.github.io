# Agent Lifecycle Console (synthetic)

Phone-friendly static prototype for Sycamore Member of Product Staff interview practice.

## Wedge
Go-live to monitor to retire console for a fake bank ops agent, matched to Sycamore Forge + Guard lifecycle language. Not an eval grid.

## Run
Open `index.html` in a browser. No build step. No network calls on the happy path.

## 90-second path
1. Roster to select Wire Exception Triage Agent
2. Ownership to Fix wildcard on wire.release
3. Go-live to Clear dry-run policy block to Go Live
4. Monitor to Approve the pending run to Incident to Roll back
5. Retire to Drain to reason + signature to Retire to Evidence
