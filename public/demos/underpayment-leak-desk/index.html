    Autonomy rule

    The agent may do alone

    • Flag a gap between expected and paid.
    • Group gaps by root cause.
    • Mark "Not a leak" when the gap fully matches a patient responsibility line on the remit.

    A human must approve

    • Any gap of $500 or more.
    • Any case with agent confidence under 85%.
    • Any case where the contract clause is missing. Approve stays locked until a clause is linked.
    • Only approved cases add to CFO-confirmed dollars.
    • Send back to agent needs a short note. The case returns as Needs review with the note shown.
