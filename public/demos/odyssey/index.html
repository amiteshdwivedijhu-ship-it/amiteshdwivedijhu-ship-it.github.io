Trajectory Review

Given a recorded multi-agent trajectory from a shared simulation, the harness returns an eval packet: trajectory score, pass/fail, cited failure modes, and a next training priority. Every failure tag cites a frame range from the run. The rubric is written before the run and cannot move; packets are computed from raw frames, never hand-labeled.
