Hard product rule The agent may go live only when all are true: (1) UAT accuracy on money and reference fields (rate, linehaul plus accessorials total, customer reference / PO, pickup and delivery appointment) is 100% on the UAT set, (2) all other fields are at least 98%, (3) zero open exceptions in the queue, (4) a second run on the same UAT set gives identical output, and (5) customer UAT signoff is recorded with a name and date. If any check fails, Go Live stays locked and the reason is visible.
