# Policy Dry Run

Unlisted static prototype. Open `index.html`. No build step and no network calls.

Synthetic company Brightline Freight. Not a Merge product. Week totals are seeded. The drill-down table is a sample of last 7 days, not the source of those totals.

This is a before-and-after check for an employee AI policy change. It is not a tool registry. Publish stays locked until the dry run is current, critical workflows are clear or excepted, rollback v12 is on file, and an employee note is written.
