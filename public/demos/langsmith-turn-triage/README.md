# Turn Triage

Unlisted static prototype. Open `index.html` in a browser. No build step and no network calls.

Synthetic SkyHarbor Air rebooking threads. Not a LangChain or LangSmith product.

The hero is the turn timeline with the break turn marked. A thread score only says the thread failed. This view names the turn, then sends it to an annotation queue, a dataset example, or an automation rule after a backtest.
